# 개발 실행 안내 (Godot 4.7.2 / Android)

## 이 버전에서 실제 구현한 기능
- 60Hz 정수 기반 전투 틱, 이동/점프/대시/회피/3타 연계 공격
- Godot 기본 물리에 직접 의존하지 않는 AABB 타격 판정
- 타격 순간과 같은 데이터를 사용하는 화면상의 타격 영역 표시
- 공격당 1회 타격 제한, 회피 무적, 피격 경직/넉백
- 상태 스냅샷/복원, 입력 재생 자동 테스트
- 갤럭시 탭 터치 버튼 및 PC 키보드 입력
- 비주얼은 **임시 벡터 도형**. 백설/상미의 최종 원화와 애니메이션은 아직 미적용.

## 태블릿에서 할 일
1. Godot 4.7.2 Android 에디터를 설치/실행.
2. GitHub의 `feature/godot-core` 브랜치를 ZIP으로 내려받고 압축 해제.
3. `project.godot` 파일을 Godot Android 에디터에서 열기.
4. 메인 장면 `scenes/training_room.tscn`를 실행(▶).
5. 화면 하단 터치 버튼으로 이동/점프/공격/회피/대시 테스트.
6. 오류 발생 시 Godot Output / Debugger의 오류 전문과 발생 상황을 공유.

PC에서는 A/D 또는 방향키로 이동, Space 점프, J/Z 공격, K/X 회피, Shift 대시, R 재시작.

## 검증 기준
- Android에서 프로젝트가 파싱 및 실행되는지
- 백설이 3연속 공격을 이어갈 수 있는지
- 청록색 경계선이 표시한 영역이 실제 판정과 일치하는지
- 회피 중 무적이 동작하는지
- 프레임 안정성, 터치 동시 입력, 방향 전환을 확인
- GitHub Actions가 가져온 Godot 4.7.2로 3개 자동 테스트를 통과하는지

## 주의
이 코드의 수학적 재생 테스트는 플랫폼 차이를 줄이기 위한 시작점이다. Godot 엔진의 모든 연산이 결정적이라고 주장하지 않는다. 특히 `int(float(vx) * .8)` 같은 계산은 향후 정수 나눗셈으로 치환할 계획이다. **네트워크 PvP, 계정, 거래 및 서버 백업은 아직 구현하지 않았다.**
