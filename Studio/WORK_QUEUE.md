# Dreamwalker 제작 스튜디오 작업 기록

작업 브랜치 `feature/tablet-production-studio` · PR #3 · 서비스 https://dreamwalker-snowfield-studio.congenialcockatoo.chatgpt.site/

## 검증된 작업

- 웹 제작 도구에서 맵 가로 100~3200, 세로 100~1600, 층별 배치와 경계 축소 시 위치 확인을 지원한다. 100단위가 한 화면이다.
- 카메라 여유 폭, 지수 추적, 배경 시차와 정지 시 바람 움직임, 왕복 발판을 작성할 수 있다. 웹에서 수직 이동과 탑승을 시험했다.
- 웹 기본 검격에 준비·판정·회복 틱과 입력 버퍼, 한 검격당 대상 1회 판정을 적용했다. Unity 스튜디오 모드에도 같은 틱과 부채꼴 공식을 적용했다. 네이티브 실행 검증은 남아 있다.
- 브라우저에서 맵 이동 시 남은 HP, 처치와 플래그를 보존한다. 기존 진행을 저장하고 새 실행에서 복원하는 테스트를 추가했다. 웹 브라우저 기기 로컬 저장이다.
- 조건부 버튼만 있는 일시정지 화면 검출, 막힌 터치 화면의 복귀 조작을 추가했다. 편집 초안에 있는 연결되지 않은 화면은 경고한다.
- 웹 플레이에서 화면과 겹치는 정적 개체만 생성하고 성능 표시를 추가했다. Node 회귀 테스트에서 160개 소품·600개 카메라 위치의 검사 후보가 96,000개에서 4,946개로 줄었다. 실기기 FPS 측정과 별도다.

## 이어갈 작업

1. 외주 프레임·판정·효과 타임라인, 적 공격 준비/회복·보스 단계, 인벤토리/장비/퀘스트 보상 데이터와 게임 UI 연결.
2. 공동 초안, 버전 간 변경 병합, 팀원의 검토 제출과 소유자 승인. Android 빌드 경로와 실기기 로그, 게임 빌드에서 저장·복원, 두 기기 네트워크 검증.
3. 테스트된 변경을 기존 사이트에 배포하고 배포 상태와 링크를 확인한다. Unity Editor·Android 실기기 실행 여부를 구분한다.

재개 시 PR의 최신 커밋과 이 파일부터 읽는다. 다른 실행이 작업 중이면 병합 전까지 중복 작업을 피한다. 원격 진행이 멈췄으면 다음 미완료 묶음부터 작업한다. 모든 조건이 검증되면 완료와 링크를 보내고 자동 작업을 중지한다.
